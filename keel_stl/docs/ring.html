module kl::ring

class ring

#class ring<T>

A fixed-capacity double-ended queue of T that owns its elements and the block holding them.

Elements are added and removed at either end in constant time, and indexed from 0 at the front. A ring never grows on its own: pushing onto a full one panics, try_push_back hands the element back, and push_back_evict makes room by removing the element at the other end. Only reserve changes the capacity. Dropping the ring drops every element.

#public optional<T> push_back_evict( move T value )

Adds value at the back, first removing and returning the front element if the ring is full.

Returns none when there was room, so nothing was removed.

#public optional<T> push_front_evict( move T value )

Adds value at the front, first removing and returning the back element if the ring is full.

Returns none when there was room, so nothing was removed.

#public void reserve( u64 n )

Makes room for at least n elements in all, not n more, moving the elements into a new block in order. Does nothing if the capacity is already that large.

#public void clear()
