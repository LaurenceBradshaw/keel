enum parse_error

#enum parse_error

Why string::parse_i64 refused its text.

Variants

#no_digits

There are no digits: the text is empty, or only -.

#invalid_digit( u64 index )

The byte at index cannot continue the number.

#overflow

The number lies outside the range of i64.

class string

#class string implements textual, equatable, hashable, from<str>, from<u64>, from<i64>, from<joined_text>

A growable sequence of bytes that owns its storage.

The bytes are not checked to be UTF-8, and every index and size counts bytes.

Parsing

#public result<i64, parse_error> parse_i64() const

The i64 the string writes in decimal.

The text is an optional - and then one or more digits 0 to 9, which may have leading zeros. Nothing else is read: not a +, whitespace or a separator.

Errors

no_digits if there are no digits, invalid_digit naming the first byte that cannot continue the number, and overflow as soon as the number leaves the range of i64.
