enum optional

#enum optional<T>

A value of type T, or nothing.

Variants

#some( T value )

Holds a value.

#none

Holds nothing.

function unwrap

#T unwrap<T>( move optional<T> o )

Takes the value out of an optional, panicking if there is none.

Panics

If o is none.

function expect

#T expect<T>( move optional<T> o, str message )

Takes the value out of an optional, panicking with a given message if there is none.

Panics

If o is none, with message.

function value_or

#T value_or<T>( move optional<T> o, move T fallback )

Takes the value out of an optional, or a fallback if there is none.

Returns fallback if o is none; an unused fallback is dropped.

function is_some

#bool is_some<T>( const ref optional<T> o )

Whether an optional holds a value.

#bool is_none<T>( const ref optional<T> o )
