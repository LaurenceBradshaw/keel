module kl::ndarray

class ndarray

#class ndarray<T> where T : numeric

Numbers of any rank with a shape set at run time, held row-major: the last index moves fastest.

The operators work element by element, with a scalar on either side, and two arrays of different shapes panic. a[i, j, k] takes one index per dimension. An array owns its elements, so copy() is the way to a second one.

Constructors

#public ndarray( const ref T[] elements, u64... shape )

elements row after row, in shape, or as one dimension when no shape is given: ndarray<f64>( [1.0, 2.0, 3.0, 4.0], 2, 2 ). Panics when the shape does not hold exactly as many elements.

Products

#public T dot( const ref ndarray<T> o ) const

The inner product with o, both of rank 1 and one length.

#public ndarray<T> matmul( const ref ndarray<T> b ) const

The matrix product with b, each of rank 1 or 2. A rank 1 array is a row on the left and a column on the right, and that dimension is dropped from the result, so two of them give rank

  1. Ranks above 2 panic.
#public ndarray<T> transposed() const

The rows as columns. Rank 0 and 1 come back unchanged, and ranks above 2 panic.

Comparing

#public bool operator==( const ref ndarray<T> o ) const

Whether o has this shape and every element equals the matching one.

#public bool approx_equal( const ref ndarray<T> o, T rtol = 1e-5, T atol = 1e-8 ) const where T : floating

Whether o has this shape and every |a - b| <= atol + rtol * |b|, b being o's element. A NaN is close to nothing, and an infinity only to itself.

Reducing

#public T sum() const

The total of every element, added in index order.

Converting

#public ndarray<U> to<U>() const where U : numeric, where T : converts_to<U>

Each element converted by cast, which panics on a value U cannot hold. A float to an integer needs a rounding: truncated, rounded, floored or ceiled.

#public ndarray<U> truncated<U>() const where U : integral, where T : floating

Each element toward zero, as a U. Panics on an infinity, a NaN, or a value U cannot hold.

#public ndarray<U> rounded<U>() const where U : integral, where T : floating

Each element to the nearest, a half away from zero, as a U. Panics on an infinity, a NaN, or a value U cannot hold.

#public ndarray<U> floored<U>() const where U : integral, where T : floating

Each element down, as a U. Panics on an infinity, a NaN, or a value U cannot hold.

#public ndarray<U> ceiled<U>() const where U : integral, where T : floating

Each element up, as a U. Panics on an infinity, a NaN, or a value U cannot hold.
