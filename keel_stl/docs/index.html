The Keel standard library

package kl

The Keel standard library.

Each module is imported by name through the package, import kl::list;, and its declarations are written through the package too, kl::list<i32>.

Modules

command_line

flag struct
A flag that command_line::add_flag declared: present or absent, with no value.
option struct
An option that command_line::add_option declared: absent, or given with a value.
command_line class
The options a program accepts, which parse its arguments and describe them in a usage text.
parsed_arguments class
What command_line::parse read: which flags and options were given, their values, and the positionals.

console

Standard output

print function
Writes text to standard output, ending no line.
println function
Writes text and then a newline, as print does.

Standard error

eprint function
Writes text to standard error, ending no line.
eprintln function
Writes text and then a newline, as eprint does.

Standard input

input function
Reads the next line of standard input into line, without its \n, answering false at the end of input. A read error is also false; the careful path is file::standard_input().

hash_control

hash_control class
The control bytes, counts and key of a hash table, without its keys or values.
hash_probe class
The slots of a hash_control whose tag matches a hash, in probe order.

list

list class
A growable array of T that owns its elements and the block holding them.

map

map class
A hash table from keys of type K to values of type V, each key held at most once.

optional

optional enum
A value of type T, or nothing.
unwrap function
Takes the value out of an optional, panicking if there is none.
expect function
Takes the value out of an optional, panicking with a given message if there is none.
value_or function
Takes the value out of an optional, or a fallback if there is none.
is_some function
Whether an optional holds a value.
is_none function
Whether an optional holds nothing.

ordered_control

ORDERED_KEYS global
ORDERED_MIN global
ORDERED_NO_NODE global
key_run struct
count key slots moving from from.. to to... The two may overlap.
key_moves struct
Up to three runs, applied in order. A run not needed has count 0.
ordered_control class
The shape of a B-tree: each node's children, key count and subtree size, and the free nodes.

ordered_map

ordered_map class
A B-tree from keys of type K to values of type V, each key held at most once, in ascending order.

ordered_set

ordered_set class
A B-tree of keys of type K, each held at most once, in ascending order.

os

Errors

os_error enum
A failure any call to the system can meet.
file_error enum
Why a call on a file, a path or a directory failed.

Paths

path class
A file-system path, held as written and never normalised: a/../b stays as it is.
path_kind enum
What, if anything, is at a path. A symbolic link counts as what it points to.
path_kind_of function
What is at name. Nothing there is path_kind::missing, not an error.
exists function
Whether anything is at name; false too when the system cannot say.
is_file function
Whether name is a regular file; false too when the system cannot say.
is_directory function
Whether name is a directory; false too when the system cannot say.

Files

file_mode enum
How file::open opens a file. Every mode but read creates a file that does not exist.
file class
An open file, closed when it is dropped.
read_file function
The whole of the file at name.
write_file function
Writes data to the file at name, replacing what it held, or creating it.
delete_file function
Deletes the file at name. A directory is file_error::is_directory.

Directories

create_directory function
Creates the directory name, whose parent must exist. Anything already there is file_error::exists.
create_directories function
Creates the directory name and each missing parent. Levels already there are left as they are, so a directory that exists is success.
delete_directory function
Deletes the empty directory name. One still holding something is file_error::not_empty, and a file is file_error::not_directory.
list_directory function
Every entry in the directory name but . and .., each joined onto name, in the system's order.

Processes

process class
A running program, waited for when it is dropped, so dropping one that has not ended blocks until it does.
captured class
A finished program's exit code and what it wrote to its standard output, as capture answers.
run function
Runs program with arguments to its end and answers its exit code, as process::wait does. Input this program has already buffered is not seen by the child.
capture function
Runs program with arguments to its end and answers its exit code and its standard output. Its standard error is still this program's.

Environment

environment function
The value of the environment variable name, or none when it is not set; a name that is empty or holds = never is.
program_path function
The path of this program's executable, with every symbolic link resolved.
current_directory function
The current working directory, as an absolute path.

pair

pair class
Two values, of possibly different types, held together.

ring

ring class
A fixed-capacity double-ended queue of T that owns its elements and the block holding them.

set

set class
A hash table of keys of type K, each held at most once.

string

parse_error enum
Why string::parse_i64 refused its text.
string class
A growable sequence of bytes that owns its storage.
same_text function
Whether a and b hold the same bytes in the same order.

time

Durations

duration class
A span of time in whole nanoseconds, which may be negative; one holds about 292 years either way.

Clocks

instant class
A reading of the monotonic clock, which never goes backwards and is never stepped, but is rate-corrected towards true seconds. Only meaningful against another instant.
raw_instant class
A reading of the oscillator's own clock, never corrected, for comparing this machine's clock against another's. Use instant for measuring.
wall_time function
Nanoseconds since 1970-01-01 UTC, which can step when the system clock is set; measure with instant.

package kl::test

Unit tests: named test functions, checks that report their caller's line, and a runner that gives each test a process of its own.

A test module imports kl::test::context; the suite's main imports kl::test::run.

test::context

context class
What a test checks through. A failed check is counted and reported, and the test goes on; a failed require ends it.

test::run

entry struct
A test and the name run reports it by.
run function
Runs the tests that args selects, each in a process of its own, and answers main's exit code: 0 when every test passed, 1 when any failed, 2 for an unknown option.

Prelude

Every program also sees the prelude without an import.
