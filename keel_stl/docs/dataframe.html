class series

#class series

One column of a dataframe: values of one dtype, any of which may be missing.

A missing f64 is a NaN, as in pandas; the other dtypes keep a mask of missing values, so an i64 column with a gap stays i64. + - * / work element by element against a series of the same size or a number: two i64 sides stay i64, / always gives f64, and a value missing on either side is missing in the result. The comparisons answer a mask that is clear where a value is missing, for dataframe::filtered. The reductions skip missing values and answer f64, a bool counting as 0 or 1. s.f64s() and its siblings hand a loop the values, panicking on another dtype.

class dataframe

#class dataframe

Named series of one length, in order, with rows numbered from 0, as pandas' DataFrame.

Build one empty and insert columns, or read one with read_csv. df["a"] is a column; head, tail, iloc, filtered, select and sort_values answer new frames holding copies, as pandas' copy-on-write behaves, while insert, set, drop and rename change the frame itself. groupby answers a grouped. to_string writes pandas' table.

class grouped

#class grouped

The groups dataframe::groupby makes: the rows sharing their values in the key columns, the groups in sorted key order, and rows missing a key left out.

Each reduction answers a frame of the keys, one row a group, then a column for each other column: count counts every column, while the rest skip strings columns, as pandas' numeric_only. sum, min and max keep an i64s column i64s, and min and max keep bools bools; the others answer f64s, a bool counting as 0 or 1.

function parse_csv

#result<dataframe, csv_error> parse_csv( const ref textual text, u8 sep = ',' )

The frame CSV text holds, read as RFC 4180 with pandas' defaults.

The first line names the columns. Fields are split at sep; a quoted field may hold sep, line breaks and doubled quotes. Blank lines are skipped, and a row short of fields has the rest missing, as are pandas' missing tokens (an empty field, NA, NaN, null, None and the like). Each column takes the first dtype every value present reads as, i64s, f64s, then bools (True, False, and lower or upper case), else strings; a column with no values present is f64s.
