class duration

#class duration implements equatable, comparable

A span of time in whole nanoseconds, which may be negative; one holds about 292 years either way.

Clocks

class instant

#class instant implements equatable, comparable

A reading of the monotonic clock, which never goes backwards and is never stepped, but is rate-corrected towards true seconds. Only meaningful against another instant.

Methods

#public static instant now()

The clock's reading now.

#public static duration resolution()

The clock's resolution.

The time from earlier to this one, negative if earlier is later.

class raw_instant

#class raw_instant implements equatable, comparable

A reading of the oscillator's own clock, never corrected, for comparing this machine's clock against another's. Use instant for measuring.

#i64 wall_time()

Nanoseconds since 1970-01-01 UTC, which can step when the system clock is set; measure with instant.
