The Keel standard library

package kl

The Keel standard library.

Each module is imported by name through the package, import kl::list;, and its declarations are written through the package too, kl::list<i32>.

Takes the value out of an optional, panicking with a given message if there is none.
value_or function
Takes the value out of an optional, or a fallback if there is none.
is_some function

is_none function
