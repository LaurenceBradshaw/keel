module kl::stats

class regression

#class regression

A least-squares fit of y on the columns of a design x, as statsmodels' OLS and WLS: regression::ols( x, y ) or regression::wls( x, y, w ), then the coefficients, residuals, scale, leverage, Cook's distance and covariances, and from a covariance the standard errors, p-values and intervals.

The p-values and intervals take the coefficients as normal, as statsmodels does for a robust covariance such as cluster_cov. For cov() statsmodels uses Student's t with df_resid() degrees of freedom instead, which kl does not have, so there they differ for a small sample.

Methods

#public static optional<regression> wls( const ref ndarray<f64> x, const ref ndarray<f64> y, const ref ndarray<f64> w )

The fit of rank 1 y on rank 2 x, n by k with n >= k, each row weighted by the matching one of rank 1 w, by kl::lstsq on the rows scaled by the square roots of the weights; none when x lacks full column rank.

Panics

If x has more columns than rows, or y or w is not one element per row of x.

#public static optional<regression> ols( const ref ndarray<f64> x, const ref ndarray<f64> y )

wls with every weight 1.

#public const ref ndarray<f64> coef() const

The coefficients, one per column of the design.

#public const ref ndarray<f64> resid() const

y less the fitted values, unweighted.

#public const ref ndarray<f64> wresid() const

The residuals scaled by the square roots of the weights.

#public f64 scale() const

The residual variance: the sum of the squared wresid() over df_resid().

#public u64 df_resid() const

The rows less the columns of the design.

#public ndarray<f64> leverage() const

Each row's leverage: the diagonal of the projection onto the weighted design's columns.

#public ndarray<f64> cooks_distance() const

Each row's Cook's distance over the weighted design, as statsmodels' cooks_distance.

#public ndarray<f64> cov() const

The coefficients' covariance, k by k, scale() (X^T X)^-1 over the weighted design X.

#public ndarray<f64> cluster_cov( const ref u64[] groups ) const

The cluster-robust covariance, k by k, as statsmodels' cov_type="cluster": rows with the same label in groups are one cluster, and the sandwich takes statsmodels' correction, G / ( G - 1 ) * ( n - 1 ) / ( n - k ) for G clusters.

Panics

If groups is not one label per row.

#public ndarray<f64> std_errors( const ref ndarray<f64> cov ) const

The standard errors from covariance cov, the square roots of its diagonal.

#public ndarray<f64> p_values( const ref ndarray<f64> cov ) const

Each coefficient's two-sided p-value against 0 under covariance cov, from the normal.

#public ndarray<f64> conf_int( const ref ndarray<f64> cov, f64 alpha = 0.05 ) const

The 1 - alpha interval of each coefficient under covariance cov, from the normal, k by 2: each row its low and high ends, as statsmodels' conf_int( alpha ).
