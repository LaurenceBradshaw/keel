The Keel standard library

module kl::map

class map

#class map<K, V> where K : hashable

A hash table from keys of type K to values of type V, each key held at most once.

Keys are kept in the order they were inserted until a removal, which moves the last key into the removed one's place. key_at and value_at count over them: for( u64 i : 0..m.size() ). Each map hashes under its own random key, so which keys collide cannot be chosen from outside. A full map doubles, so insert takes amortised constant time; with_capacity and reserve make room in advance. Dropping the map drops every key and value.

Construction

#public map()

An empty map. Allocates nothing until the first key arrives.

#public static map<K, V> with_capacity( u64 capacity )

An empty map with room for capacity keys before it grows.

#~map()

Size and capacity

#public u64 size() const

The number of keys.

#public bool is_empty() const

Whether the map holds no keys.

#public u64 capacity() const

How many keys fit before the map grows. Removing a key may lower it until the map is rebuilt.

#public void reserve( u64 n )

Makes room for at least n keys in all, not n more. Does nothing if the capacity is already that large.

Lookup

#public optional<V*> get( const ref K key ) const

A pointer to the value under key, or none if the map does not hold it.

#public V* operator[]( const ref K key ) const

A pointer to the value under key.

Panics

If the map does not hold key; get answers none instead.

#public bool contains( const ref K key ) const

Whether the map holds key.

By position

#public const K* key_at( u64 i ) const

A pointer to the key of entry i, counting from 0 in insertion order until a removal. const, since a changed key would sit in the wrong slot.

Panics

If i is not less than size().

#public V* value_at( u64 i ) const

A pointer to the value of entry i, the value under key_at( i ).

Panics

If i is not less than size().

Changing

#public optional<V> insert( move K key, move V value )

Puts value under key, and returns the value that was there, or none if there was none.

When the key is already present, the map keeps its own key and key is dropped.

#public optional<V> remove( const ref K key )

Removes key and returns its value, or none if the map does not hold it. The last entry takes its place.

#public void clear()

Drops every key and value; the capacity is kept.
