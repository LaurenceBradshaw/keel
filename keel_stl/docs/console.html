function print

#void print( const ref textual text )

Writes text to standard output, ending no line.

#void print( i64 value )

Writes an integer in decimal.

#void print( u64 value )

Writes an integer in decimal.

#void print( f64 value )

Writes a float in the fewest digits that read back as the same value.

A whole number gains .0, and a NaN is written nan.

#void print( bool value )

Writes true or false.

function eprint

#void eprint( const ref textual text )

Writes text to standard error, ending no line.

Standard output is flushed first, so what both show stays in order.

#void eprint( i64 value )

Writes an integer in decimal.

#void eprint( u64 value )

Writes an integer in decimal.

#void eprint( f64 value )

Writes a float in the fewest digits that read back as the same value.

A whole number gains .0, and a NaN is written nan.

#void eprint( bool value )

Writes true or false.

function input

#bool input( ref string line )

Reads the next line of standard input into line, without its \n, answering false at the end of input. A read error is also false; the careful path is file::standard_input().
