function sort

#void sort<C, T, F>( ref C items, F less ) where C : fixed_memory<T>, where F : fn( const ref T, const ref T ) -> bool

Orders items so no element is less than the one before it.

A heap sort: O(n log n) and in place, but equal elements may change order.

function index_of

#optional<u64> index_of<C, T, F>( const ref C items, F matches ) where C : fixed_memory<T>, where F : fn( const ref T ) -> bool

The index of the first element matches picks, or none.

function contains

#bool contains<C, T, F>( const ref C items, F matches ) where C : fixed_memory<T>, where F : fn( const ref T ) -> bool

Whether matches picks any element.

function binary_search

#optional<u64> binary_search<C, T, F>( const ref C items, F compare ) where C : fixed_memory<T>, where F : fn( const ref T ) -> ordering

The index of an element compare calls equal, or none.

compare says how each element orders against the one sought, and items must already be in that order. Which of several equal elements it finds is unspecified.

function remove_if

#void remove_if<C, T, F>( ref C items, F drop ) where C : dynamic_memory<T>, where F : fn( const ref T ) -> bool

Drops every element drop picks, keeping the rest in order.

function dedup

#void dedup<C, T, F>( ref C items, F same ) where C : dynamic_memory<T>, where F : fn( const ref T, const ref T ) -> bool

Drops each element same calls equal to the one kept before it, so sorted items keep one of each run.

function array

#T[N] array<T, u64 N, F>( F make ) where F : fn( u64 ) -> T

An array whose element at each index is make( index ), made in index order.

T and N come from the type the result is given to: buf[4] bufs = kl::array( fn[]( i ) { return buf( i ); } );.
