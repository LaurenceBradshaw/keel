function dft

#complex<T>[N] dft<T, u64 N>( const ref complex<T>[N] x ) where T : floating

The DFT of x: y[k] is the sum over j of x[j] e^(-2 pi i j k / N).

The transforms here follow scipy.fft: the forward one unnormalised, the inverse scaled by 1 / N. Each is written as its definition, a sum over every input for every output. At -O3 that sum is solved into a fast circuit for its N; below -O3 it runs as written, in O(N^2).

function idft

#complex<T>[N] idft<T, u64 N>( const ref complex<T>[N] y ) where T : floating

The inverse DFT, conj( dft( conj( y ) ) ) / N, so idft( dft( x ) ) is x to rounding.

function rdft

#complex<T>[N / 2 + 1] rdft<T, u64 N>( const ref T[N] x ) where T : floating

The DFT of the real x, its first N / 2 + 1 outputs; the rest are their conjugates, y[N - k] being conj( y[k] ).

function irdft

#T[N] irdft<T, u64 N>( const ref complex<T>[N / 2 + 1] y ) where T : floating

The real N points whose rdft is y, N given: kl::irdft<f64, 8>( y ). As numpy's irfft, the imaginary parts of y[0] and, for an even N, y[N / 2] are not read.
