module kl::ordered_set

class ordered_set

#class ordered_set<K> where K : comparable

A B-tree of keys of type K, each held at most once, in ascending order.

kl::ordered_map without the values: key_at counts over the keys from the smallest, and rank finds where a key sits among them, both in logarithmic time. Dropping the set drops every key.

Construction

#public ordered_set()

An empty set. Allocates nothing until the first key arrives.

#~ordered_set()

Size

#public u64 size() const

The number of keys.

#public bool is_empty() const

Whether the set holds no keys.

Lookup

#public bool contains( const ref K key ) const

Whether the set holds key.

By position

#public const K* key_at( u64 i ) const

A pointer to the ith smallest key, counting from 0. const, since a changed key would be out of order.

Panics

If i is not less than size().

#public u64 rank( const ref K key ) const

The number of keys less than key, which is where key sits or would sit.

Changing

#public bool insert( move K key )

Adds key, and returns whether it was new. A key already present is kept, and key is dropped.

#public bool remove( const ref K key )

Removes key, and returns whether the set held it.

#public void clear()

Drops every key; the capacity is kept.
