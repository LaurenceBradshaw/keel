The Keel standard library

package kl

The Keel standard library.

Each module is imported by name through the package, import kl::list;, and its declarations are written through the package too, kl::list<i32>.

Modules

console

print function
Writes text to standard output, ending no line.
eprint function
Writes text to standard error, ending no line.
println function
Writes text and then a newline, as print does.
eprintln function
Writes text and then a newline, as eprint does.
input function
Reads the next line of standard input into line, without its \n, answering false at the end of input. A read error is also false; the careful path is file::standard_input().

hash_control

hash_control class
The control bytes, counts and key of a hash table, without its keys or values.
hash_probe class
The slots of a hash_control whose tag matches a hash, in probe order.

list

list class
A growable array of T that owns its elements and the block holding them.

map

map class
A hash table from keys of type K to values of type V, each key held at most once.

optional

optional enum
A value of type T, or nothing.
unwrap function
Takes the value out of an optional, panicking if there is none.
expect function
Takes the value out of an optional, panicking with a given message if there is none.
value_or function
Takes the value out of an optional, or a fallback if there is none.
is_some function
Whether an optional holds a value.
is_none function
Whether an optional holds nothing.

ordered_control

ORDERED_KEYS global
ORDERED_MIN global
ORDERED_NO_NODE global
key_run struct
count key slots moving from from.. to to... The two may overlap.
key_moves struct
Up to three runs, applied in order. A run not needed has count 0.
ordered_control class
The shape of a B-tree: each node's children, key count and subtree size, and the free nodes.

ordered_map

ordered_map class
A B-tree from keys of type K to values of type V, each key held at most once, in ascending order.

ordered_set

ordered_set class
A B-tree of keys of type K, each held at most once, in ascending order.

os

os_error enum
A failure any call to the system can meet.
file_error enum
Why a call on a file, a path or a directory failed.
path class
A file-system path, held as written and never normalised: a/../b stays as it is.
path_kind enum
What, if anything, is at a path. A symbolic link counts as what it points to.
path_kind_of function
What is at name. Nothing there is path_kind::missing, not an error.
exists function
Whether anything is at name; false too when the system cannot say.
is_file function
Whether name is a regular file; false too when the system cannot say.
is_directory function
Whether name is a directory; false too when the system cannot say.
file_mode enum
How file::open opens a file. Every mode but read creates a file that does not exist.
file class
An open file, closed when it is dropped.
read_file function
The whole of the file at name.
write_file function
Writes data to the file at name, replacing what it held, or creating it.
delete_file function
Deletes the file at name. A directory is file_error::is_directory.
create_directory function
Creates the directory name, whose parent must exist. Anything already there is file_error::exists.
delete_directory function
Deletes the empty directory name. One still holding something is file_error::not_empty, and a file is file_error::not_directory.
list_directory function
Every entry in the directory name but . and .., each joined onto name, in the system's order.

pair

pair class
Two values, of possibly different types, held together.

ring

ring class
A fixed-capacity double-ended queue of T that owns its elements and the block holding them.

set

set class
A hash table of keys of type K, each held at most once.

string

parse_error enum
Why string::parse_i64 refused its text.
string class
A growable sequence of bytes that owns its storage.

Prelude

Every program also sees the prelude without an import.
