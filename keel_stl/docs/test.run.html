function run

#i32 run( const ref entry[] tests, const ref str[] args )

Runs the tests that args selects, each in a process of its own, and answers main's exit code: 0 when every test passed, 1 when any failed, 2 for an unknown option.

Each argument is an option or a filter. A test runs when its name contains any filter, or when there is none.

  • --list prints the selected names and runs nothing.
  • --no-fork runs every test in this process, so a panic ends the run; for a debugger.

Each test's result is a line on stdout, pass <name> or FAIL <name>, then the counts.
