class fixed_list

#class fixed_list<T, u64 N> implements iterable<T>, dynamic_memory<T>

A list of at most N elements of T, held inline: it never allocates.

Elements sit side by side, indexed from 0, in a T[?N] of which the first size() slots hold a value. Pushing onto a full list panics, and try_push hands the element back instead. Dropping the list drops every element, last to first.
