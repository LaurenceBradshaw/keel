class vec

#class vec<T, u64 N> implements iterable<T> where T : numeric

N numbers held inline: a vector of rank 1, neither a row nor a column.

The operators work element by element, with a scalar on either side. v.dot( w ) is the inner product, and v.matmul( m ) reads v as a row.

class mat

#class mat<T, u64 R, u64 C> implements iterable<T> where T : numeric

R rows of C numbers held inline, row after row: a matrix of rank 2.

The operators work element by element, with a scalar on either side; m.matmul( b ) is the matrix product, and m.matmul( v ) reads v as a column. m[r, c] is row r, column c, and for( T x : m ) walks the elements row after row.
