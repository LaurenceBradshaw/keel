class ndarray

#class ndarray<T> implements iterable<T> where T : numeric

Numbers of any rank with a shape set at run time, held row-major: the last index moves fastest.

The operators work element by element, with a scalar on either side. Two arrays broadcast: their shapes line up from the right, and a dimension of 1 or a missing one stretches to the other's, so a (3, 4) array plus a (4) adds the row to each row. Other shapes panic, as does a compound assignment whose result would not keep the left side's shape. a[i, j, k] takes one index per dimension. An array owns its elements, so copy() is the way to a second one. for( T x : a ) walks the elements in that order.

Fields

#public static const u64 inferred

Stands for one dimension reshaped works out from the others.

Constructors

Slices

#public ndarray<T> sliced( range... region ) const

A copy of region, one range per dimension: a.sliced( 1..3, 0..a.shape()[1] ). Panics on another count, a backwards range, or one past its dimension.

#public void assign( const ref ndarray<T> src, range... region )

Writes src into region, whose lengths must be src's shape. Panics as sliced does, or when the shapes differ.

#public void fill( T x, range... region )

Sets every element of region to x. Panics as sliced does.

#public ref T[] row( u64 i ) const

Row i of a matrix, as a run writable where the array is. Panics unless the rank is 2, or when i is outside the first dimension.

#public ref T[] block( u64... at ) const

The elements under the leading indices at, as a run writable where the array is: a.block( i, j ) of a rank 3 array is its [i, j, ..] row. Panics on more indices than dimensions, or an index outside its dimension.

Products

#public T dot( const ref ndarray<T> o ) const

The inner product with o, both of rank 1 and one length.

#public ndarray<T> matmul( const ref ndarray<T> b ) const

The matrix product with b, each of rank 1 or 2. A rank 1 array is a row on the left and a column on the right, and that dimension is dropped from the result, so two of them give rank

  1. Ranks above 2 panic.
#public ndarray<T> transposed() const

The axes reversed: a matrix's rows as columns. Rank 0 and 1 come back unchanged.

#public ndarray<T> diagonal() const

The diagonal of a rank 2 array, as rank 1.

#public T trace() const

The sum of the diagonal of a rank 2 array.

#public ndarray<T> outer( const ref ndarray<T> b ) const

Each element times each of b, both read flat: an a.size() by b.size() array.

#public T norm() const where T : floating

The square root of the sum of squares: the length at rank 1, the Frobenius norm at rank 2. It overflows only when the norm does.

#public ndarray<T> normalised() const where T : floating

This array over its norm(); every element NaN when that is 0.

#public bool approx_equal( const ref ndarray<T> o, T rtol = 1e-5, T atol = 1e-8 ) const where T : floating

Whether o has this shape and every |a - b| <= atol + rtol * |b|, b being o's element. A NaN is close to nothing, and an infinity only to itself.

Converting

#public ndarray<U> truncated<U>() const where U : integral, where T : floating

Each element toward zero, as a U. Panics on an infinity, a NaN, or a value U cannot hold.

#public ndarray<U> rounded<U>() const where U : integral, where T : floating

#public ndarray<U> floored<U>() const where U : integral, where T : floating

function inverse
