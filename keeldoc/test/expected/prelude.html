primitive bool

#bool

true or false.

Conditions, &&, ||, == and != take one. Nothing converts to a bool, and cast makes an integer of one.

primitive i8

#i8

A signed 8-bit integer, from -128 to 127.

Arithmetic on it wraps, and a constant out of its range is refused. It converts implicitly to i16, i32, i64, f32 and f64.

primitive i16

#i16

A signed 16-bit integer, from -32768 to 32767.

Arithmetic on it wraps, and a constant out of its range is refused. It converts implicitly to i32, i64, f32 and f64.

primitive i32

#i32

A signed 32-bit integer, from -2147483648 to 2147483647.

Arithmetic on it wraps, and a constant out of its range is refused. It converts implicitly to i64 and f64.

primitive i64

#i64

A signed 64-bit integer, from -9223372036854775808 to 9223372036854775807.

Arithmetic on it wraps, and a constant out of its range is refused. No other type holds all its values, so it converts to none implicitly.

primitive u8

#u8

An unsigned 8-bit integer, from 0 to 255.

Arithmetic on it wraps, and a constant out of its range is refused. It converts implicitly to i16, i32, i64, u16, u32, u64, f32 and f64.

primitive u16

#u16

An unsigned 16-bit integer, from 0 to 65535.

Arithmetic on it wraps, and a constant out of its range is refused. It converts implicitly to i32, i64, u32, u64, f32 and f64.

primitive u32

#u32

An unsigned 32-bit integer, from 0 to 4294967295.

Arithmetic on it wraps, and a constant out of its range is refused. It converts implicitly to i64, u64 and f64.

primitive u64

#u64

An unsigned 64-bit integer, from 0 to 18446744073709551615.

Arithmetic on it wraps, and a constant out of its range is refused. No other type holds all its values, so it converts to none implicitly.

primitive f32

#f32

A 32-bit floating-point number.

It converts implicitly to f64. Nothing converts it to an integer.

primitive f64

#f64

A 64-bit floating-point number.

No other type holds all its values, so it converts to none implicitly. Nothing converts it to an integer.

primitive void

#void

No value: what a function that yields nothing returns.

It takes no storage. As a type argument it is accepted, so result<void, E> succeeds with result::ok(); written directly, a void parameter, field or global is refused.

primitive never

#never

The return type of a function that does not return.

A call of one ends its block, and a switch arm ending in one needs no break. It is a return type and nothing else: a function's, an extern's or a function pointer's.

class str

#class str implements textual

Text: a run of bytes and their count.

A string literal is a str, and only a literal makes one. Its size counts the bytes after escapes are decoded, a \0 included.

enum result

#enum result<T, E>

The outcome of something that can fail: a T, or an E saying why not.

try takes the value out of an ok, or returns an err from the function it is in. A result left unused is refused; _ = f(); discards one on purpose.

Variants

#ok( T value )

Succeeded, with a value.

#err( E error )

Failed, with why.

enum ordering

#enum ordering

How one value compares with another, as operator<=> answers.

a < b, a <= b, a > b and a >= b all come from a <=> b. On a float, <=> panics if either operand is a NaN, which has no order, while < and its kin answer false.

Variants

#less

The left operand comes first.

#equal

Neither comes first.

#greater

The right operand comes first.

class box

#class box<T>

One T on the heap, owned: dropping the box drops the value and frees its memory.

A box<Circle> goes wherever a box<Shape> is wanted when Circle implements Shape, and the value is then called and dropped through Shape's vtable. box is the one type that takes an interface as its type argument.

interface equatable

#interface equatable

A type whose values can be tested for equality.

a != b comes from a == b. Numbers, bool, pointers and enums without payloads are equatable without writing anything.

Methods

#public bool operator==( const ref self other ) const

Whether this value equals other.

interface comparable

#interface comparable implements equatable

A type whose values have an order.

a < b, a <= b, a > b and a >= b come from a <=> b. Numbers are comparable without writing anything.

Methods

#public ordering operator<=>( const ref self other ) const

How this value compares with other.

interface hashable

#interface hashable implements equatable

A type whose values hash to a u64.

Values that are == must hash the same, so a type that writes its own == writes its own hash too. Numbers, bool, pointers and enums without payloads are hashable without writing anything; a float's hash counts -0.0 as 0.0, and panics on a NaN.
