module kl::ordered_map

class ordered_map

#class ordered_map<K, V> where K : comparable

A B-tree from keys of type K to values of type V, each key held at most once, in ascending order.

key_at and value_at count over the keys from the smallest, and rank finds where a key sits among them, all in logarithmic time: for( u64 i : m.rank( lo )..m.rank( hi ) ) visits the keys from lo up to but not including hi. Dropping the map drops every key and value.

Constructors

Methods

#public optional<V> insert( move K key, move V value )

Puts value under key, and returns the value that was there, or none if there was none.

When the key is already present, the map keeps its own key and key is dropped.

#public optional<V*> get( const ref K key ) const

A pointer to the value under key, or none if the map does not hold it.

#public V* operator[]( const ref K key ) const

A pointer to the value under key.

Panics

If the map does not hold key; get answers none instead.

#public const K* key_at( u64 i ) const

A pointer to the ith smallest key, counting from 0. const, since a changed key would be out of order.

Panics

If i is not less than size().

#public V* value_at( u64 i ) const

A pointer to the value under key_at( i ).

Panics

If i is not less than size().

#public u64 rank( const ref K key ) const

The number of keys less than key, which is where key sits or would sit.

#public bool contains( const ref K key ) const

Whether the map holds key.

#public optional<V> remove( const ref K key )

Removes key and returns its value, or none if the map does not hold it.

#public u64 size() const

The number of keys.

#public bool is_empty() const

Whether the map holds no keys.

#public void clear()

Drops every key and value; the capacity is kept.
