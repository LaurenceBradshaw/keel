class regression

#class regression<u64 N(dyn), u64 K(dyn)> where N >= K

A least-squares fit of y on the K columns of an N by K design x, as statsmodels' OLS and WLS: kl::ols( x, y ) or kl::wls( x, y, w ), then the coefficients, residuals, scale, leverage, Cook's distance and covariances, and from a covariance the standard errors, p-values and intervals. A design of ndarray<f64, dyn, 3> gives coefficients of ndarray<f64, 3> and covariances of ndarray<f64, 3, 3>.

The p-values and intervals take the coefficients as normal, as statsmodels does for a robust covariance such as cluster_cov. For cov() statsmodels uses Student's t with df_resid() degrees of freedom instead, which kl does not have, so there they differ for a small sample.

Methods

#public static optional<regression<N, K>> wls( const ref ndarray<f64, N, K> x, const ref ndarray<f64, N> y, const ref ndarray<f64, N> w )

The fit of y on x, each row weighted by the matching one of w, by kl::lstsq on the rows scaled by the square roots of the weights; none when x lacks full column rank. kl::wls( x, y, w ) writes it without the sizes.

#public static optional<regression<N, K>> ols( const ref ndarray<f64, N, K> x, const ref ndarray<f64, N> y )

wls with every weight 1.

#public const ref ndarray<f64, K> coef() const

The coefficients, one per column of the design.

#public const ref ndarray<f64, N> resid() const

y less the fitted values, unweighted.

#public const ref ndarray<f64, N> wresid() const

The residuals scaled by the square roots of the weights.

#public f64 scale() const

The residual variance: the sum of the squared wresid() over df_resid().

#public u64 df_resid() const

The rows less the columns of the design.

#public ndarray<f64, N> leverage() const

Each row's leverage: the diagonal of the projection onto the weighted design's columns.

#public ndarray<f64, N> cooks_distance() const

Each row's Cook's distance over the weighted design, as statsmodels' cooks_distance.

#public ndarray<f64, K, K> cov() const

The coefficients' covariance, K by K, scale() (X^T X)^-1 over the weighted design X.

#public ndarray<f64, K, K> cluster_cov( const ref ndarray<u64, N> groups ) const

The cluster-robust covariance, K by K, as statsmodels' cov_type="cluster": rows with the same label in groups, one per row, are one cluster, and the sandwich takes statsmodels' correction, G / ( G - 1 ) * ( n - 1 ) / ( n - k ) for G clusters.

#public ndarray<f64, K> std_errors( const ref ndarray<f64, K, K> cov ) const

The standard errors from covariance cov, the square roots of its diagonal.

#public ndarray<f64, K> p_values( const ref ndarray<f64, K, K> cov ) const

Each coefficient's two-sided p-value against 0 under covariance cov, from the normal.

#public ndarray<f64, K, 2> conf_int( const ref ndarray<f64, K, K> cov, f64 alpha = 0.05 ) const

The 1 - alpha interval of each coefficient under covariance cov, from the normal, K by 2: each row its low and high ends, as statsmodels' conf_int( alpha ).
