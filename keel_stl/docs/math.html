Bits

function bits_of

#u64 bits_of( f64 x )

The bits of x, sign first: bits_of( 1.0 ) is 0x3FF0000000000000.

#u32 bits_of( f32 x )

The bits of x, sign first: the f32 1.0 has 0x3F800000.

The f32 whose bits are x.

Roots

function sqrt

#f64 sqrt( f64 x )

The square root of x, correctly rounded: NaN below zero, and -0.0 for -0.0.

#f32 sqrt( f32 x )

The square root of x, correctly rounded: NaN below zero, and -0.0 for -0.0.

Trigonometry

global pi

#const f64 pi

The f64 nearest to the ratio of a circle's circumference to its diameter.

function sin

#f64 sin( f64 x )

The sine of an angle in radians.

Within an ulp of the true value. An infinity or a NaN gives NaN, and -0.0 stays -0.0.

function cos

#f64 cos( f64 x )

The cosine of an angle in radians.

Within an ulp of the true value. An infinity or a NaN gives NaN.

function tan

#f64 tan( f64 x )

The tangent of an angle in radians.

Within an ulp of the true value. An infinity or a NaN gives NaN, and -0.0 stays -0.0.

function asin

#f64 asin( f64 x )

The angle in [-π/2, π/2] whose sine is given.

Within an ulp of the true value. Outside [-1, 1], or at NaN, it is NaN.

function acos

#f64 acos( f64 x )

The angle in [0, π] whose cosine is given.

Within an ulp of the true value. Outside [-1, 1], or at NaN, it is NaN.

function atan

#f64 atan( f64 x )

The angle in [-π/2, π/2] whose tangent is given.

Within an ulp of the true value. NaN gives NaN, and -0.0 stays -0.0.
