The Keel standard library

module kl::set

class set

#class set<K> implements iterable<K> where K : hashable

A hash table of keys of type K, each held at most once.

kl::map without the values: keys are kept in insertion order until a removal moves the last key into the removed one's place, key_at counts over them, each set hashes under its own random key, and insert takes amortised constant time. Dropping the set drops every key.

Construction

#public set()

An empty set. Allocates nothing until the first key arrives.

#public static set<K> with_capacity( u64 capacity )

An empty set with room for capacity keys before it grows.

#~set()

Size and capacity

#public u64 size() const

The number of keys.

#public bool is_empty() const

Whether the set holds no keys.

#public u64 capacity() const

How many keys fit before the set grows. Removing a key may lower it until the set is rebuilt.

#public void reserve( u64 n )

Makes room for at least n keys in all, not n more. Does nothing if the capacity is already that large.

Lookup

#public bool contains( const ref K key ) const

Whether the set holds key.

By position

#public const K* key_at( u64 i ) const

A pointer to key i, counting from 0 in insertion order until a removal. const, since a changed key would sit in the wrong slot.

Panics

If i is not less than size().

Iteration

#public void operator:( const ref K key ) const

Each key once, in key_at's order: for( const ref K k : s ). The body may not change the set.

Changing

#public bool insert( move K key )

Adds key, and returns whether it was new. A key already present is kept, and key is dropped.

#public bool remove( const ref K key )

Removes key, and returns whether the set held it. The last key takes its place.

#public void clear()

Drops every key; the capacity is kept.
