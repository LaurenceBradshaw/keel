module kl::bitset

struct bitset

#struct bitset<u64 N> implements equatable, hashable

A fixed set of N bits, indexed from 0.

A bitset copies like a number. kl::bitset<64> {} is one with every bit clear. Every method that takes an index panics when it is not less than N.

Fields

#public u64[(N + 63) / 64] words = [ 0, .. ]

The bits, 64 to a word, from bit 0 of the first word. The last word's bits past N are spare: every reader ignores them, so they may hold anything.

Comparing and combining
