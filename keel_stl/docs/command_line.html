class command_line

#class command_line

The options a program accepts, which parse its arguments and describe them in a usage text.

--name sets a flag. --name value and --name=value set an option. -- ends the options, and every other argument is a positional.

Constructors

#public command_line( str synopsis )

No options yet. synopsis follows usage: , as keelb <build|test> [options].

Methods

#@located public flag add_flag( str name, str help )

Declares --name, which help describes. name is written without the dashes.

Panics when name is empty, starts with -, or is already declared.

#@located public option add_option( str name, str placeholder, str help )

Declares --name <placeholder>, which help describes. name is written without the dashes.

Panics when name is empty, starts with -, or is already declared.

#public string usage() const

The usage line, then each declaration with its help, in the order they were added.

#public result<parsed_arguments, string> parse( const ref str[] args ) const

Reads main's arguments, or answers why they cannot be read, as a sentence to print after the program's name.

Refuses an unknown or short option, an option without its value, a flag with one, and anything given twice. An option's value is the next argument even when it starts with -.
