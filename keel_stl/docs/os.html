enum os_error

#enum os_error

A failure any call to the system can meet.

Variants

#interrupted

A signal arrived before the call finished; trying again may succeed.

#out_of_memory

The system had no memory for the call.

#other( i32 code )

Any other failure, with the system's own errno value.

enum file_error

#enum file_error

Why a call on a file, a path or a directory failed.

Variants

#not_found

Nothing exists at the path.

#denied

The file or a directory on its path does not allow it.

#exists

Something is already at the path, and file_mode::create_new or create_directory was asked for.

#is_directory

The path names a directory where a file was wanted.

#not_directory

A name on the path, or the path itself, should be a directory and is not one.

#not_empty

The directory to delete still holds something.

#os( os_error error )

A failure that is not particular to files.

class path

#class path implements textual, from<str>

A file-system path, held as written and never normalised: a/../b stays as it is.

A literal converts to one, so kl::path p = "a"; works.

Methods

#public static path from( str text )

The path text, which is how a literal becomes one.

#public static path of( const ref textual text )

The path text, from a kl::string, another path or anything textual.

#public const ref u8[] as_text() const

The path's bytes, as written.

#public path operator/( const ref textual part ) const

part joined on with one /. An absolute part, or an empty path, gives part alone.

#public path parent() const

Everything before the last /: a/b gives a, /a and / give /, and a gives the empty path.

#public string file_name() const

Everything after the last /, or the whole path with none: a/ has the empty name.

#public string extension() const

The file name from its last ., the dot included: b.tar.gz gives .gz. Empty with no dot, and a leading dot does not count, so .bashrc, . and .. have none.

enum path_kind

#enum path_kind

What, if anything, is at a path. A symbolic link counts as what it points to.

Variants

#missing

Nothing, including a path through something that is not a directory.

#file

A regular file.

#directory

A directory.

#other

Anything else, such as a device or a pipe.

enum file_mode

#enum file_mode

How file::open opens a file. Every mode but read creates a file that does not exist.

Variants

#read

Read only, from the start.

#write

Write only, emptying the file first.

#append

Write only, every write going at the end.

#create_new

Write only, failing with file_error::exists if the file is there already.

class file

#class file

An open file, closed when it is dropped.

Made by file::open, or for the program's own streams by standard_input, standard_output and standard_error, which never close them. Reads go through a buffer, and writes straight to the system.

Constructors

#~file()

Methods

#public static result<file, file_error> open( const ref textual name, file_mode mode )

Opens the file at name in mode.

#public static file standard_input()

The program's standard input. Every one shares a buffer, so none loses what another read.

#public static file standard_output()

The program's standard output, flushed by every write.

#public static file standard_error()

The program's standard error. Standard output is flushed first, so the two keep their order.

#public result<u64, file_error> read( ref u8[] into )

Reads into into, answering how many bytes it put there: at most into.size, and 0 only at the end of the file. Fewer than asked for is not the end; ask again.

#public result<void, file_error> write( const ref textual data )

Writes all of data.

#public result<string, file_error> read_all()

Reads the rest of the file.

#public result<bool, file_error> read_line( ref string line )

Reads up to the next \n, which is dropped, into line, replacing what it held. false only when the input ends before any byte, so a last line without \n is still a line.

class process

#class process

A running program, waited for when it is dropped, so dropping one that has not ended blocks until it does.

Constructors

#~process()

Methods

#public static result<process, file_error> start<T>( const ref textual program, const ref T[] arguments ) where T : textual

Starts program, found through PATH unless it holds a /, with arguments. No shell reads them, and the child shares this program's standard streams. Input this program has already buffered is not seen by the child.

#public result<i32, os_error> wait()

Waits for the program to end and answers its exit code, or 128 and the signal's number when a signal ended it. Asked again, it answers the same.

function run

#result<i32, file_error> run<T>( const ref textual program, const ref T[] arguments ) where T : textual

Runs program with arguments to its end and answers its exit code, as process::wait does. Input this program has already buffered is not seen by the child.
