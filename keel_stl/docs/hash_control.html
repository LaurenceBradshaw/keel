class hash_control

#class hash_control

The control bytes, counts and key of a hash table, without its keys or values.

kl::map and kl::set hold one each beside their own arrays, and a slot of those arrays is live exactly when is_full says so. Use kl::map or kl::set rather than this directly.

The slots to rebuild with when needs_growth(): double, unless tombstones rather than keys used up the room, when the same size clears them. Without that, churn would double a table forever.

#public static u64 match_tags( u64 word, u64 tags )

Flags each byte of word equal to the tag that fills every byte of tags.

Bytes above a match may be flagged too, but only full ones, so comparing their keys rejects them.

class hash_probe

#class hash_probe

The slots of a hash_control whose tag matches a hash, in probe order.

It reads the table's groups directly, so it must not outlive a rebuild.

Constructors

#public hash_probe( u64[*] groups, u64 slots, u64 hash )

A probe of groups, a table of slots slots, for hash.

Methods

#public u64 next()

The next slot whose tag matches, or the slot count once no further slot can hold the key. Keeps answering the slot count after that.
