class array

#class array<T, u64... S(dyn)> implements iterable<T> where T : numeric

Numbers in the shape S, held row-major: the last index moves fastest.

Each size is a constant, array<f64, 4, 4>, or known only when the program runs, array<f64, dyn, 3>. A small array of constant sizes is held inline, any other on the heap; the same code works with either. kl::zeros( rows, 3 ) makes one from sizes, and a call checks at run time what the types cannot.

The operators work element by element, with a scalar on either side. Two arrays broadcast: their shapes line up from the right, and a size of 1 or a missing one stretches to the other's. A compound assignment keeps the left side's shape. An array owns its elements, so copy() is the way to a second one. for( T x : a ) walks the elements in row-major order.

class array_mask

#class array_mask<u64... S(dyn)>

One bit per element of an array in the shape S, held row-major: what its comparisons answer.

&, |, ^ and ~ combine masks bit by bit. kl::select( m, a, b ) picks between two arrays by one, and a.selected( m ) keeps the elements of a it sets.
