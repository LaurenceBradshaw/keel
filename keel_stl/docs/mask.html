class mask

#class mask

One bit per element of an ndarray, in a shape set at run time, held row-major.

&, |, ^ and ~ combine masks bit by bit, and two masks of different shapes panic. kl::select( m, a, b ) picks between two arrays by one, and a.selected( m ) keeps the elements of a it sets.

Constructors

#public mask( u64... shape )

Every bit clear, in shape. No shape is rank 0, one bit.
