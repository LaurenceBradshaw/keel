The Keel standard library

module kl::iterable

interface iterable

#interface iterable<T>

A container a loop can read through, one T at a time.

A bound only: a walk is lowered where its loop is written, so where C : kl::iterable<T> is the one way to take any of them, and for( const ref T x : c ) then reads each element in the container's own order.

Methods

#public void operator:( const ref T item ) const

Lends each element to the loop in turn.
