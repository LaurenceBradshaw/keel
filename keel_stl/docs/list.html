module kl::list

class list

#class list<T>

A growable array of T that owns its elements and the block holding them.

Elements sit side by side, indexed from 0. A full list doubles its capacity, so push takes amortised constant time. Dropping the list drops every element.

#public void insert( u64 index, move T value )

#public void truncate( u64 n )

#public T remove( u64 index )

Removes the element at index and returns it, moving every later element one place earlier. Keeps the order and takes linear time; swap_remove does neither.

If index is not less than size().

#public T swap_remove( u64 index )

Removes the element at index and returns it, moving the last element into its place. Takes constant time and does not keep the order.

Panics

If index is not less than size().

#public T replace( u64 index, move T value )

If index is not less than size().

#public void swap( u64 a, u64 b )

#public void reserve( u64 n )

Makes room for at least n elements in all, not n more. Does nothing if the capacity is already that large.

#public void shrink_to_fit()

Reduces the capacity to the number of elements, freeing the block if there are none.
