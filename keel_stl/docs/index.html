The Keel standard library

package kl

The Keel standard library.

Each module is imported by name through the package, import kl::list;, and its declarations are written through the package too, kl::list<i32>.

Modules

list

list class
A growable array of T that owns its elements and the block holding them.

optional

optional enum
A value of type T, or nothing.
unwrap function
Takes the value out of an optional, panicking if there is none.
expect function
Takes the value out of an optional, panicking with a given message if there is none.
value_or function
Takes the value out of an optional, or a fallback if there is none.
is_some function
Whether an optional holds a value.
is_none function
Whether an optional holds nothing.

pair

pair class
Two values, of possibly different types, held together.

ring

ring class
A fixed-capacity double-ended queue of T that owns its elements and the block holding them.

string

parse_error enum

string class
