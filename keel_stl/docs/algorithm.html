function sort

#void sort<C, T, F>( ref C items, F less ) where C : fixed_memory<T>, where F : fn( const ref T, const ref T ) -> bool

Orders items so no element is less than the one before it.

Pattern-defeating quicksort: O(n log n) and in place, near O(n) on input already in order or all equal, but equal elements may change order.

#void sort<C, T>( ref C items ) where C : fixed_memory<T>, where T : comparable

Orders items from least to greatest, as sort( ref items, less ) with <.

function nth_element

#void nth_element<C, T, F>( ref C items, u64 k, F less ) where C : fixed_memory<T>, where F : fn( const ref T, const ref T ) -> bool

Puts at k the element sort( ref items, less ) would, with none after it less than it and none before it that it is less than, as C++'s nth_element: O(n) on average and in place. Does nothing when k is not less than items.size().

function sum

#T sum<C, T>( const ref C items ) where C : fixed_memory<T>, where T : numeric

The total of items, 0 when there are none; added pairwise, as ndarray::sum and numpy do.

function median

#T median<C, T>( const ref C items ) where C : fixed_memory<T>, where T : floating

The middle value of items, or the mean of the two middle ones; NaN when there are none or one is NaN, as numpy's median. Selects on a copy, so items keeps its order.

function stable_sort

#void stable_sort<C, T, F>( ref C items, F less ) where C : fixed_memory<T>, where F : fn( const ref T, const ref T ) -> bool

Orders items so no element is less than the one before it, keeping equal elements in order.

O(n log n): insertion sorts blocks of 20, then merges them, holding the left side of each merge aside in a scratch array of up to n elements. Input already in order is merged in O(n).

#void stable_sort<C, T>( ref C items ) where C : fixed_memory<T>, where T : comparable

Orders items from least to greatest, keeping equal elements in order, as stable_sort( ref items, less ) with <.

function binary_search_by

#optional<u64> binary_search_by<C, T, F>( const ref C items, F compare ) where C : fixed_memory<T>, where F : fn( const ref T ) -> ordering

The index of an element compare calls equal, or none.

compare says how each element orders against the one sought, and items must already be in that order. Which of several equal elements it finds is unspecified.

function binary_search

#optional<u64> binary_search<C, T>( const ref C items, const ref T value ) where C : fixed_memory<T>, where T : comparable

The index of an element equal to value, or none.

items must already be in order. Which of several equal elements it finds is unspecified.

function dedup

#void dedup<C, T, F>( ref C items, F same ) where C : dynamic_memory<T>, where F : fn( const ref T, const ref T ) -> bool

Drops each element same calls equal to the one kept before it, so sorted items keep one of each run.

#void dedup<C, T>( ref C items ) where C : dynamic_memory<T>, where T : equatable

Drops each element equal to the one kept before it, so sorted items keep one of each value.

function array

#T[N] array<T, u64 N, F>( F make ) where F : fn( u64 ) -> T

An array whose element at each index is make( index ), made in index order.

T and N come from the type the result is given to: buf[4] bufs = kl::array( fn[]( i ) { return buf( i ); } );.
