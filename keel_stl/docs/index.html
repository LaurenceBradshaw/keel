The Keel standard library

package kl

The Keel standard library.

Each module is imported by name through the package, import kl::list;, and its declarations are written through the package too, kl::list<i32>.

Modules

algorithm

sort function
Orders items so no element is less than the one before it.
index_if function
The index of the first element matches picks, or none.
index_of function
The index of the first element equal to value, or none.
contains_if function
Whether matches picks any element.
contains function
Whether any element equals value.
binary_search_by function
The index of an element compare calls equal, or none.
binary_search function
The index of an element equal to value, or none.
remove_if function
Drops every element drop picks, keeping the rest in order.
remove function
Drops every element equal to value, keeping the rest in order.
dedup function
Drops each element same calls equal to the one kept before it, so sorted items keep one of each run.
array function
An array whose element at each index is make( index ), made in index order.

bitset

bitset struct
A fixed set of N bits, indexed from 0.

command_line

flag struct
A flag that command_line::add_flag declared: present or absent, with no value.
option struct
An option that command_line::add_option declared: absent, or given with a value.
command_line class
The options a program accepts, which parse its arguments and describe them in a usage text.
parsed_arguments class
What command_line::parse read: which flags and options were given, their values, and the positionals.

console

Standard output

print function
Writes text to standard output, then end.

Standard error

eprint function
Writes text to standard error, then end.

Standard input

input function
Reads the next line of standard input into line, without its \n, answering false at the end of input. A read error is also false; the careful path is file::standard_input().

fixed_list

fixed_list class
A list of at most N elements of T, held inline: it never allocates.
equatable for fixed_list<T, N> where T : equatable implements
Two lists are equal when they hold equal elements in the same order.
hashable for fixed_list<T, N> where T : hashable implements
A list hashes each element in order, then its size.

iterable

iterable interface
A container a loop can read through, one T at a time.

list

list class
A growable array of T that owns its elements and the block holding them.
equatable for list<T> where T : equatable implements
Two lists are equal when they hold equal elements in the same order.
hashable for list<T> where T : hashable implements
A list hashes each element in order, then its size.

map

map class
A hash table from keys of type K to values of type V, each key held at most once.

math

Bits

bits_of function
The bits of x, sign first: bits_of( 1.0 ) is 0x3FF0000000000000.
from_bits function
The f64 whose bits are x.

Roots

sqrt function
The square root of x, correctly rounded: NaN below zero, and -0.0 for -0.0.

Classes

is_nan function
Whether x is a NaN, the one value not equal to itself.
is_inf function
Whether x is positive or negative infinity.

Sign and order

abs function
x without its sign: -0.0 gives 0.0, and a NaN stays one. The most negative integer overflows, as 0 - x does.
sign function
-1, 0 or 1 as x is below, at or above zero. A NaN stays one, and -0.0 stays -0.0.
min function
The smallest of first and rest, or a NaN when any is one: kl::min( a, b, c ).
max function
The largest of first and rest, or a NaN when any is one: kl::max( a, b, c ).

Rounding

truncated function
x toward zero, as a U: truncated<i32>( -2.7 ) is -2.
rounded function
x to the nearest whole value, a half away from zero, as a U: rounded<i32>( -2.5 ) is -3.
floored function
x down to a whole value, as a U: floored<i32>( -2.5 ) is -3.
ceiled function
x up to a whole value, as a U: ceiled<i32>( 2.1 ) is 3.
floor function
x down to a whole value: floor( -2.5 ) is -3.0. An infinity or a NaN stays one.
ceil function
x up to a whole value: ceil( -0.5 ) is -0.0. An infinity or a NaN stays one.
trunc function
x toward zero, to a whole value: trunc( -2.7 ) is -2.0. An infinity or a NaN stays one.
round function
x to the nearest whole value, a half away from zero: round( 2.5 ) is 3.0. An infinity or a NaN stays one.

Constants

pi global
The f64 nearest to the ratio of a circle's circumference to its diameter.

Exponentials and logarithms

exp function
e to the power x: an infinity above 709.78, and 0 below -745.13. Within an ulp.
expm1 function
e^x - 1, exact near 0 where exp( x ) - 1.0 loses digits: -1 below -38. Within an ulp.
log function
The natural logarithm: -inf at 0, and a NaN below. Within an ulp.
log1p function
log(1 + x), exact near 0 where log( 1.0 + x ) loses digits: -inf at -1, and a NaN below. Within an ulp.
log2 function
The base 2 logarithm, exact at powers of 2: -inf at 0, and a NaN below. Within an ulp.
log10 function
The base 10 logarithm: -inf at 0, and a NaN below. Within an ulp.
pow function
x to the power y. As C's pow: 1 when y is 0 or x is 1, even beside a NaN; a NaN for a negative x and a y that is not whole; and an odd whole y keeps x's sign. Within an ulp.

Hyperbolic functions

sinh function
The hyperbolic sine. Within 2 ulps.
cosh function
The hyperbolic cosine. Within 2 ulps.
tanh function
The hyperbolic tangent, -1 to 1. Within 2 ulps.

Trigonometry

sin function
The sine of an angle in radians.
cos function
The cosine of an angle in radians.
tan function
The tangent of an angle in radians.
asin function
The angle in [-pi/2, pi/2] whose sine is given.
acos function
The angle in [0, pi] whose cosine is given.
atan function
The angle in [-pi/2, pi/2] whose tangent is given.
atan2 function
The angle in [-pi, pi] of the point (x, y) from the positive x axis: atan2( 1.0, -1.0 ) is 3 pi / 4. Each zero's sign picks the side, as C's atan2. Within an ulp.

optional

optional enum
A value of type T, or nothing.
unwrap function
Takes the value out of an optional, panicking if there is none.
expect function
Takes the value out of an optional, panicking with a given message if there is none.
value_or function
Takes the value out of an optional, or a fallback if there is none.

Whether an optional holds a value.

Whether an optional holds nothing.

os

Errors

os_error enum
A failure any call to the system can meet.
file_error enum
Why a call on a file, a path or a directory failed.

Paths

path class
A file-system path, held as written and never normalised: a/../b stays as it is.
path_kind enum
What, if anything, is at a path. A symbolic link counts as what it points to.
path_kind_of function
What is at name. Nothing there is path_kind::missing, not an error.
exists function
Whether anything is at name; false too when the system cannot say.
is_file function
Whether name is a regular file; false too when the system cannot say.
is_directory function
Whether name is a directory; false too when the system cannot say.

Files

file_mode enum
How file::open opens a file. Every mode but read creates a file that does not exist.
file class
An open file, closed when it is dropped.
read_file function
The whole of the file at name.
write_file function
Writes data to the file at name, replacing what it held, or creating it.
delete_file function
Deletes the file at name. A directory is file_error::is_directory.

Directories

create_directory function
Creates the directory name, whose parent must exist. Anything already there is file_error::exists.
create_directories function
Creates the directory name and each missing parent. Levels already there are left as they are, so a directory that exists is success.
delete_directory function
Deletes the empty directory name. One still holding something is file_error::not_empty, and a file is file_error::not_directory.
list_directory function
Every entry in the directory name but . and .., each joined onto name, in the system's order.

Processes

process class
A running program, waited for when it is dropped, so dropping one that has not ended blocks until it does.
captured class
A finished program's exit code and what it wrote to its standard output, as capture answers.
run function
Runs program with arguments to its end and answers its exit code, as process::wait does. Input this program has already buffered is not seen by the child.
capture function
Runs program with arguments to its end and answers its exit code and its standard output. Its standard error is still this program's.

Environment

platform enum
An operating system a program can be built for.
get_platform function
The operating system this program was built for.
environment function
The value of the environment variable name, or none when it is not set; a name that is empty or holds = never is.
program_path function
The path of this program's executable, with every symbolic link resolved.
current_directory function
The current working directory, as an absolute path.

pair

pair class
Two values, of possibly different types, held together.
equatable for pair<A, B> where A : equatable, where B : equatable implements
Two pairs are equal when both their values are.
comparable for pair<A, B> where A : comparable, where B : comparable implements
Pairs order by their first values, then by their second.
hashable for pair<A, B> where A : hashable, where B : hashable implements
A pair hashes its first value, then its second.

ring

ring class
A double-ended queue of at most N elements of T, held inline: it never allocates.
equatable for ring<T, N> where T : equatable implements
Two rings are equal when they hold equal elements in the same order from the front.
hashable for ring<T, N> where T : hashable implements
A ring hashes each element from the front, then its size.

set

set class
A hash table of keys of type K, each held at most once.

string

parse_error enum
Why string::parse_i64 refused its text.
string class
A growable sequence of bytes that owns its storage.
same_text function
Whether a and b hold the same bytes in the same order.
join function
The parts with separator between each pair: join( [ "a", "b" ], ", " ) gives "a, b".

time

Durations

duration class
A span of time in whole nanoseconds, which may be negative; one holds about 292 years either way.

Clocks

instant class
A reading of the monotonic clock, which never goes backwards and is never stepped, but is rate-corrected towards true seconds. Only meaningful against another instant.
raw_instant class
A reading of the oscillator's own clock, never corrected, for comparing this machine's clock against another's. Use instant for measuring.
wall_time function
Nanoseconds since 1970-01-01 UTC, which can step when the system clock is set; measure with instant.

package kl::test

Unit tests: named test functions, checks that report their caller's line, and a runner that gives each test a process of its own.

A test module imports kl::test::context; the suite's main imports kl::test::run.

test::context

context class
What a test checks through. A failed check is counted and reported, and the test goes on; a failed require ends it.

test::run

entry struct
A test and the name run reports it by.
run function
Runs the tests that args selects, each in a process of its own, and answers main's exit code: 0 when every test passed, 1 when any failed, 2 for an unknown option.
